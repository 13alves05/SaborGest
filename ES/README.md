# Engenharia de Software (ES)

Esta pasta reúne as atividades de Engenharia de Software que incluem conteúdo diretamente relacionado com o projeto SaborGest.

## Documentos incluídos

- `ES_A03_LeonardoAlves.md` - Product Request: problema, utilizadores, funcionalidades iniciais, prioridades e condições do SaborGest.
- `ES_A05_LeonardoAlves.md` - Processo de Desenvolvimento: enquadramento, estado do projeto, fluxo iterativo, tarefas e validação.
- `ES_A07_LeonardoAlves.md` - Princípios Agile: aplicação dos princípios Agile ao SaborGest.
- `ES_A08_LeonardoAlves.md` - Metodologias Agile: aplicação de XP, Scrum e Kanban ao SaborGest.

## Critério de seleção

Foram incluídas as atividades que contêm secções ou exemplos específicos do SaborGest. As atividades 04 e 06 e a Atividade 09 não foram incluídas porque o conteúdo enviado aborda conceitos ou casos genéricos, sem aplicação direta ao SaborGest.

## Formato

Os documentos foram transcritos para Markdown a partir dos PDFs enviados, preservando o conteúdo textual. Os PDFs originais não foram alterados nem substituídos no material de origem.
